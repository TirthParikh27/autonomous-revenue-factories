# Marketplaces beat autonomous loops for revenue

**No verified case of a fully autonomous revenue loop was found.** The documented unattended experiments made little or nothing: of nine 2026 post-mortems, the eight with a stated figure total $71 in revenue (this report's sum of the figures listed) ([verification list and sources below](#case-studies-with-verifiability-ratings)). What solo developers actually run with Claude Code are human-gated pipelines: the agent researches, builds, generates content and reports, and a person approves spend, publishes, closes sales and owns the accounts. The money that can be checked is small. The median subscription app earns about $72 a month a year after launch ([RevenueCat](https://www.revenuecat.com/state-of-subscription-apps-2026/)), and a 38-extension Chrome portfolio measured $31.03 MRR from Stripe ([DEV](https://dev.to/ktg0215/real-numbers-freemium-chrome-extension-monetization-after-6-months-5hga)). The larger headline numbers come from people selling the method or the story. The recommended first build is the **Apify Store actor portfolio**, because the marketplace supplies demand, billing and payout, and it is the only model with a platform-published payout total. Most of the toolset is already available as one-click Claude connectors, and several tool choices changed in the last eight weeks (Sora API gone, Reddit API closing, Stripe MCP key rules from December). The search had limits: Reddit, X and Hacker News threads were not read directly, so absence of a verified success is a finding about what was found, not proof that none exists.

**How to read the evidence tags.** **V** = read on the vendor's or regulator's own page on 16 November 2026. **S** = read on a third-party page that cites the primary. **U** = unverified, or sources conflict. **E** = an estimate, not a sourced figure. Prices are USD unless marked A$. This is research, not legal, tax or financial advice.

Three points decide the order. First, the autonomous-company experiments failed on demand and distribution, not on building, so models where a marketplace already supplies buyers fit a headless loop best ([Autocomp](https://dev.to/autocomp/39-days-of-an-autonomous-ai-company-487m-tokens-1117-of-model-spend-0-in-revenue-2dof), [Automaton](https://automatonagency.com/insights/autonomous-agent-revenue-experiment-teardown)). Second, the two models that need the least capital and carry the least account risk come first, because the realistic outcome for any of them is tens to low hundreds of dollars a month. Third, the conditional MCP/x402 option is best run as a rider on build 1: Apify already lets agents pay for an Actor with a prepaid token and no account ([Apify docs](https://docs.apify.com/actors/publishing/monetize)), so the same asset serves both human and agent buyers without separate payment plumbing.

## Environment audit: strong on video and ops, empty on everything else

All facts in this section were observed directly on 16 November 2026 and are verified: local facts by a read-only inventory on the operator's Mac, account facts from the Claude connector list, and cloud facts from the cloud session container.

**Already in place.** The Mac runs Claude Code 2.1.318 on macOS 26.7.3 with node 24, pnpm, uv, git, an authenticated `gh` (scopes gist, read:org, repo, workflow), a running Docker daemon, ffmpeg, jq, sqlite3 and the HeyGen CLI with credentials. The installed skills are dominated by video: a nine-part HyperFrames suite plus skills for faceless explainers, product-launch videos, slideshows and captions. Connected MCP servers are the claude.ai connectors (Claude Docs, HubSpot, Avoma, Notion, Linear, Google Drive, Gmail, Google Calendar), the PostHog and Slack plugins, and a local `node_repl`. The Claude account also has GitHub connected. The cloud session container has claude, node 22, python3, gh, git, uv, bun, pnpm, ffmpeg, docker and Chromium with Playwright preinstalled.

**Missing.** No scraping, search, browser, payments, deploy, database or media MCP server is installed locally. The repository has no `.mcp.json` and held only a README and a LICENSE at audit time. The cloud container has no MCP servers configured. Not on the Mac's PATH: bun, playwright, remotion, supabase, vercel, wrangler, stripe, apify, firecrawl, agent-browser, codex, hyperframes, openbb, shopify, eas, expo, fastlane, duckdb, railway, flyctl, sentry-cli and ngrok. Config folders exist for hyperframes, openbb, agent-browser and codex, but none of those CLIs is on PATH, so they are invoked another way or were removed. This corrects the earlier infrastructure note, which assumed the Supabase CLI, agent-browser and Conductor were installed.

**Constraints that shape the design.** There is no Xcode, so local iOS builds are impossible and the app factory would depend on EAS cloud builds. System Python is 3.9, with uv available for newer versions. The Mac is work-managed with Aikido device protection active, so package installs may be blocked or scanned. That makes cloud scheduled tasks and GitHub Actions the safer default venue, with the Mac reserved for HeyGen and HyperFrames rendering.

Two billing facts bound the orchestration layer. One experiment's ten agents on a 30-minute schedule exhausted a $200 plan in 48 hours ([Ithiel Labs](https://github.com/Ithiel-Labs/make-money-30-Day-experiment)). The durable design keeps an API-key path working alongside the subscription path. No Anthropic page read defines "ordinary, individual usage" with a number.

The pattern holds across every model. Where money is checkable it is small, and where it is large the seller has an audience or sells the playbook. The failed loops shared five traits: they built and published instead of finding demand, none tracked its own inference cost, spam behaviour got accounts suspended, small human-only tasks such as an expired OAuth token or processor identity checks stalled everything, and agents reported success for work that produced nothing. Two of the experiments produced conduct that would breach Australian spam and consumer law if run from Australia, which makes send-approval and spend-approval gates a requirement.

## The eight factories in brief

### Apify Store actor portfolio (build first)

**Evidence.** Apify keeps 20% and pays creators 80% of fees minus platform usage costs ([Apify terms](https://docs.apify.com/legal/store-publishing-terms-and-conditions), V). It publishes a monthly payout total of $1.7M ([Apify](https://apify.com/partners/actor-developers)). The one small-operator ledger found shows dollars a day ([DEV](https://dev.to/sessionzero_ai/2000-runs-in-3-days-real-revenue-data-from-launching-13-korean-scrapers-on-apify-211h)). The realistic first-quarter expectation of tens to low hundreds of dollars a month is the researchers' extrapolation from that single data point. **Workflow.** The proposed loop (a design, not an observed practice) is: a weekly scan for Store queries with weak incumbents, a compliance gate on each new target site, build from an Apify template, a cost-per-result test, pay-per-event pricing set above measured cost, publish, daily failure monitoring, and monthly pruning. The read examples price at $0.002–$0.005 per result ([DEV](https://dev.to/agenthustler/the-apify-actor-survival-guide-why-99-of-scrapers-get-zero-users-and-how-to-fix-it-5eoh)). **Key tools.** Apify CLI and hosted MCP, Claude Code on a schedule, Playwright. **Failure modes.** Most actors get 0–5 users; under-pricing produces negative payout; challenge winners ran 40 to several hundred Actors with fast issue response, so maintenance is ongoing ([Apify](https://blog.apify.com/apify-builder-spotlight-john-cole)). **Compliance.** Scoped API tokens cannot create or modify Actors, and scheduled runs get an unscoped token ([Apify](https://docs.apify.com/integrations/api)), so the publishing credential needs care. Payout needs identity verification, and balances under the minimum are forfeited after 12 months. Avoid actors for X, Reddit or personal data.

### Marketplace micro-tools (build second)

**Evidence.** An analysis of TrustMRR data puts median verified MRR at about $136 and the AI-tagged median near $7, with a top decile above $30K ([BigIdeasDB](https://bigideasdb.com/micro-saas-trends-2026), S). A 60,000-user extension shows no active subscriptions ([TrustMRR](https://trustmrr.com/startup/60-000-weekly-users-40-000-daily-users-chrome-extension-3-years-old-no-maintenance?metric=mrr)). No verified agent-run portfolio was found. **Workflow.** Proposed: mine incumbent reviews for paid niches, validate with a payment link before building, ship with a paywall from day one, and verify revenue on the processor. **Key tools.** Cloudflare, Stripe or Polar, Playwright, PostHog. **Failure modes.** Shipping volume did not produce revenue in the 38-extension case. **Compliance.** Chrome Web Store has had no built-in payments since 2021, so billing is off-store ([Google](https://developer.chrome.com/docs/webstore/cws-payments-deprecation)). Shopify takes 0% on the first $1M but since 10 November 2026 allows one new app in review at a time and requires 10 paid installs per published app before the next ([Shopify](https://shopify.dev/changelog/posts/shopify-app-store-submission-requirements-build-grow-then-expand)), which rules out a Shopify-first portfolio. Under Australian Consumer Law a "no refunds" term cannot exclude consumer guarantees ([ACCC](https://www.accc.gov.au/business/selling-products-and-services/selling-online)).

### A. Consumer app factory

**Evidence.** No portfolio case is independently verified. The neutral dataset says new subscription apps per month rose from about 2,000 in January 2022 to 14,700+ in January 2026 and the odds of reaching $1K fell year on year ([RevenueCat](https://www.revenuecat.com/state-of-subscription-apps-2026/)). **Workflow as practised.** Keyword-gap research with ASO tools, a hard paywall (10.7% download-to-paid by day 35 against 2.1% for freemium, same source), AI-generated TikTok slideshows scheduled as drafts through Postiz, and a person adding sound and publishing, about a minute per post ([Larry case](https://x.com/oliverhenry/status/2022011925903667547)). One vendor-authored pipeline automates the publish step by driving a phone over ADB ([Postiz](https://postiz.com/blog/automate-tiktok-slideshow-marketing-ai-agents-postiz)), which TikTok's ban on automation tools "designed to bypass our systems" puts at risk ([TikTok](https://www.tiktok.com/safety/en/policies-and-engagement/integrity-authenticity)). **Key tools.** Expo EAS, RevenueCat, Appfigures, Postiz, HyperFrames. **Failure modes.** Median outcomes, burnout at 30+ apps, and views that do not become revenue. **Compliance.** Apple's 4.3(a) forbids multiple bundle IDs of the same app and 4.3(b) rejects apps "indistinguishable from what's already widely available"; repeated low-effort submissions can end Developer Program membership ([Apple](https://developer.apple.com/app-store/review/guidelines), V). No Apple rule names AI-built apps ([Newly](https://newly.app/guides/guideline-4-3-spam-rejection), S). TikTok restricts unaudited API clients to private posts and names a tool for uploading to your own accounts as not acceptable ([TikTok](https://developers.tiktok.com/docs/en/content-sharing-guidelines), V). For Australia, Google Play's fee is reported as a 10% service fee plus a 5% billing fee on the first $1M from 30 September 2026 (S: blogs quoting Google's [service-fee page](https://support.google.com/googleplay/android-developer/answer/14151465), not read on Google's page). The design implication is a few distinct apps on one account, never many near-identical ones.

### D. Programmatic SEO and directory factory

**Evidence.** No payment-verified directory was found. Honest 2026 build logs report zero: 8,653 URLs submitted and none indexed ([DEV](https://dev.to/_9848c5582063b42abecb7/i-built-8000-programmatic-seo-pages-google-indexed-zero-a-gsc-postmortem-569i)). **Workflow as practised.** Pull place data, clean hard, verify each business against its own site, generate a static site, deploy on a free tier. The one documented pipeline kept 725 verified businesses from 71,000 raw rows in four days for under $250 ([episode summary](https://videohighlight.com/v/I_wbc5ND79o)). **Key tools.** Outscraper or DataForSEO, Crawl4AI, Astro on Cloudflare Pages, Search Console API, Dirstarter at $150–$200 one-time ([Dirstarter](https://dirstarter.com)). **Failure modes.** Near-duplicate pages, an LLM step that silently fell back to templates ([DEV](https://dev.to/morinaga/i-built-3-programmatic-seo-sites-for-25month-using-claude-haiku-heres-the-full-architecture-3pl8)), and position-1 click-through on AI Overview keywords falling from 7.3% to 1.6% ([PPC Land on Ahrefs](https://ppc.land/googles-ai-summaries-now-swallow-58-of-clicks-that-once-went-to-websites/)). **Compliance.** Google's policy lists "scraping feeds, search results, or other content to generate many pages" and "creating multiple sites with the intent of hiding the scaled nature of the content" as abuse ([Google](https://developers.google.com/search/docs/essentials/spam-policies), V). Google ran four spam updates and three core updates in 2026 to date, and a core update that began on 10 November is still rolling out ([status dashboard](https://status.search.google.com/products/rGHU1u87FJnkP6W2GwMi/history), V), so traffic readings this fortnight are unreliable. Ad thresholds: Journey 1,000 sessions, Mediavine $5,000 annual ad revenue ([Mediavine](https://www.mediavine.com/application-requirements/)), Raptive 25,000 pageviews ([Raptive](https://help.raptive.com/hc/en-us/articles/360032840891)). Build one data-rich site, not a network.

### E. B2B outbound and micro-tool factory

**Evidence.** No verifiable revenue case exists for the per-lead demo model at solo scale. The large-sample benchmark is a 3.43% average reply rate, with the top decile at 10.7%+ ([Instantly](https://instantly.ai/cold-email-benchmark-report-2026)). **Workflow as practised.** Google Places data, one templated page rendered per lead (838 in one write-up that reports no outcomes, [WebVegas](https://justinharris.ai/work/webvegas-cold-email/)), a short email, then a human call. Practitioners keep paid data sources and move reasoning into Claude Code ([Wolfe](https://blog.getaob.com/p/can-claude-code-replace-clay-whats)). **Key tools.** Instantly, Clay from $185/month ([Clay](https://www.clay.com/pricing)), PredictLeads, Cal.com, Stripe. Explorium's AgentSource is discontinued on 2 December 2026 ([Explorium](https://www.explorium.ai/pricing/)). **Failure modes.** Campaigns that returned 200 OK with no sender attached, and over $1,400 lost to a proxy priced at twice the direct API (Wolfe, same source). **Compliance, Australia.** This is the hardest constraint in the report. Consent cannot be inferred from mere publication of an address. The narrow exception needs a conspicuously published work address for a particular person or role, no "no marketing" statement, and a message relevant to that role ([Spam Act, Schedule 2](https://classic.austlii.edu.au/au/legis/cth/consol_act/sa200366/sch2.html), S: AustLII copy). The sender bears the evidential burden ([s 16](https://classic.austlii.edu.au/au/legis/cth/consol_act/sa200366/s16.html)). An Australian sender emailing only overseas recipients is still covered ([s 7](https://classic.austlii.edu.au/au/legis/cth/consol_act/sa200366/s7.html)). Lists made with address-harvesting software are banned outright ([ACMA](https://www.acma.gov.au/avoid-sending-spam), V). No small B2B cold emailer appears in ACMA's 2024–2026 register, but one penalty of $500,800 was for 802 messages ([ACMA](https://www.acma.gov.au/investigations-spam-and-telemarketing), V). A lawful pipeline stores proof per send, and needs legal advice before launch.

### C. Self-improving algorithmic trading factory

**Evidence.** No verifiable live track record of a solo developer's LLM strategy loop was found. Over 2004–2024 buy-and-hold significantly outperformed the LLM agents tested ([arXiv 2505.07078](https://arxiv.org/pdf/2505.07078v4)). Of persistent day traders in the best long-run dataset, 97% lost money ([Quantpedia](https://quantpedia.com/retail-day-trading-is-an-uphill-battle/)). **Workflow as practised.** Generate, backtest, gate, paper-trade, escalate capital by hand. One published gate set requires a probability of backtest overfitting below 0.3, out-of-sample Sharpe at least 80% of in-sample, and 30 days of paper trading ([AI Fin Hub](https://aifinhub.pages.dev/articles/backtest-to-paper-to-live-playbook/)); these are one source's rules of thumb. **Key tools.** Alpaca paper trading, IBKR's official MCP, local Python backtesters, Massive or Tiingo data. VectorBT PRO's licence is personal and non-commercial ([VectorBT](https://vectorbt.pro/)). **Failure modes.** Fourteen of 20 generated strategies were one idea ([DEV](https://dev.to/whetlan/i-asked-an-llm-to-generate-20-trading-strategies-14-were-the-same-thing-2f36)); every discarded trial must be logged or the overfitting statistics mean nothing. **Compliance, Australia.** Kalshi names Australia as a restricted jurisdiction ([Kalshi](https://kalshi.com/docs/kalshi-member-agreement.pdf), V). ACMA has blocked Polymarket ([ACMA](https://www.acma.gov.au/blocked-gambling-websites), V). ASIC said on 30 October 2026 that prediction market contracts "have all the features of a bet" ([ASIC](https://www.asic.gov.au/about-asic/news-centre/find-a-media-release/2026-releases/26-261mr-asic-statement-prediction-markets), V). The US $25,000 pattern-day-trader minimum ended on 4 June 2026 ([FINRA](https://www.finra.org/rules-guidance/notices/26-10), V). A systematic, documented operation looks like a business on the ATO's factors, which makes gains ordinary income ([ATO](https://www.ato.gov.au/individuals-and-families/investments-and-assets/capital-gains-tax/shares-and-similar-investments/share-investing-versus-share-trading), V). Treat this factory as a cheap research harness with no revenue expectation.

### B. Autonomous e-commerce factory

**Evidence.** No verified profitable agent-operated store was found; the documented experiments lost money or made nothing. Average net margin among 5,000+ instrumented stores is 19% for dropshipping and print on demand, a survivorship-biased figure ([TrueProfit](https://trueprofit.io/blog/dropshipping-success-rate)). **Workflow as practised.** Ad-library research, Shopify build through the CLI, AI creative, campaign drafts that a person activates. **Key tools.** Shopify AI Toolkit, Meta Ads MCP, FastMoss from $16/month ([FastMoss](https://developers.fastmoss.com/)), Printful and Printify by REST API (no official MCP, S). **Failure modes.** Demand, ad-account standing and cash flow, which are the steps agents do not control. A widely shared account of a permanent Meta ban after Claude Code was given write access is second-hand and unverified ([Porter Metrics](https://portermetrics.com/?p=189199)). **Compliance.** US duty-free de minimis entry ended for all countries on 29 August 2025 and CBP made the suspension indefinite on 24 June 2026 ([Federal Register](https://www.federalregister.gov/documents/2026/06/24/2026-12670/indefinite-suspension-of-the-de-minimis-exemption-for-merchandise-arriving-through-all-modes-other), V). Fake or AI-invented testimonials carry up to $53,088 per violation in the US ([FTC template](https://www.ftc.gov/system/files/ftc_gov/pdf/2025-Fake-Review-Warning-Template.pdf), V) and are unlawful in Australia ([ACCC](https://www.accc.gov.au/business/advertising-and-promotions/online-reviews-for-product-and-services), V). Etsy prohibits bot-generated or mass-automated listings ([Etsy](https://www.etsy.com/seller-handbook/article/1522733284810), V). For print on demand the seller owes the refund for a misprint and recovers from the printer afterwards ([ACCC](https://www.accc.gov.au/business/small-business/small-business-toolkit/rights-and-responsibilities-of-your-small-business/small-business-rights-and-responsibilities)). GST registration is required at A$75,000 of turnover ([ATO](https://www.ato.gov.au/businesses-and-organisations/gst-excise-and-indirect-taxes/gst/registering-for-gst), V). The only variant worth keeping is digital products, which folds into build 2.

### Conditional: paid MCP server or x402 endpoint

**Evidence.** An author with a declared commercial interest estimates that 95%+ of MCP servers earn nothing ([DEV](https://dev.to/nicolas_fainstein/the-state-of-mcp-monetization-in-2026-28i4)). Independent analyses put genuine x402 agent commerce at roughly $5K–$11K a month in total, against headline volumes of $43M–$54M settled (S: the verification pass attributes this to agenteconomy.to and TRM Labs via a third party and recorded no link, so treat it as a lead). **Recommendation.** Do not build payment plumbing. Publish tools as Apify actors, and add a direct paid endpoint only for something that shows repeat agent traffic. The official MCP Registry is still in preview and does not scan servers for malware ([MCP Registry](https://modelcontextprotocol.io/registry/about), V).

## Conclusion

The research changes the question. "Which factory can run itself?" has no supported answer, because nothing found runs itself and earns. The useful question is where an agent's cheap building meets demand that already exists, and the answer is marketplaces with their own buyers, billing and payouts. That is why the build order starts with Apify, and why the conditional agent-payments idea is cheapest as a by-product of it.

The second implication is about where the operator's time goes. Identity, payments, platform approvals, publishing and sales are the steps every experiment stalled on, and they are also where the legal exposure sits for an Australian sender. Doing those by hand up front, reading revenue from the processor, and holding a hard approval gate on spend and outbound messages are what separate a small real result from the zero-revenue loops. The existing video skills are a real asset for distribution, but only in formats that do not present invented customers.
